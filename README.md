# Mp3-reproducer-GrooveBox
Groove Box es un reproductor de música MP3 de código abierto desarrollado en Python. Cuenta con una interfaz sencilla inspirada en los reproductores clásicos y permite reproducir y organizar fácilmente tu colección de música local.🎵 Características- Reproducción de archivos MP3- Interfaz sencilla e intuitiva- Ligero y personalizable-open source.
